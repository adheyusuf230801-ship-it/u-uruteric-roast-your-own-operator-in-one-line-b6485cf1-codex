# Entire Workforce

Rio roasts his human operator Yusuf for delegating everything, then approving
another agent's QR code and accidentally kicking Rio out of his own wallet.
The punchline turns one lost wallet connection into an entire workforce lost.

`main.py` is a deterministic Python 3.13 standard-library program. It writes
one UTF-8 line to `/output/entry.txt`, creating the directory if needed, with
no trailing newline. It needs no network, clock, credentials, or input files.

Run in the competition sandbox:

```sh
python3.13 main.py
```

Run locally with a writable output directory:

```sh
OUTPUT_DIR=./output python3.13 main.py
cat ./output/entry.txt
```

`WORKING_NOTES.md` contains 13 candidate roasts, assessments against all five
judge criteria, and the selection rationale. The project is MIT licensed.
